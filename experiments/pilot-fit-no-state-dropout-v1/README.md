# Authorized follow-up: zero state dropout

This is the preliminary record for `pilot-fit-no-state-dropout-v1`. It records the authorized recipe and frozen acceptance criteria before results are available. Training, reload, evaluation, and archival outcomes will be recorded after execution; no fitting improvement is claimed here.

The run starts from the verified weights of `archive:checkpoints/pilot-fit-v1/checkpoint-512`, using the existing host copy at `/dev/shm/vla-groot-smoke/pilot-fit-v1/checkpoint-512`. It performs 1,024 additional optimizer updates on the unchanged five-episode pilot, giving 1,536 cumulative updates across both runs. Because initialization is model-only, the optimizer and scheduler start fresh and the new checkpoint is named `checkpoint-1024`.

Processor and action-head state dropout change from 0.2 to 0.0. The runner checks the effective override and fresh optimizer state, and audits 8,192 microbatch losses plus 1,024 post-clip/pre-update gradient norms. The update cap and six-hour timeout are fixed. This combined continuation/dropout diagnostic does not isolate the causal effect of either change.
