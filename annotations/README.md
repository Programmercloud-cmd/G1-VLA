[goal-overrides-workspace-v1.json](goal-overrides-workspace-v1.json) is the accepted overlay following the user's choice of **table/workspace-relative positions in the recorded camera view**. Left/right describes the target's workspace position, not its position relative to another box or a hard image-center threshold. It accepts 122 episodes: 76 left/front, 44 right/front, and two front-only. Episodes 0169 and 0170 retain only “at the front” because their near-center placement makes left/right unreliable. Episodes 0092, 0136, and 0165 remain on review hold.

[workspace-label-validation-v1.json](workspace-label-validation-v1.json) binds the accepted workspace overlay and frozen review, checks the decisions, and verifies all 125 original source JSON bindings. It does not record a full corrected dataset build or training run; neither has been performed. Original recordings and the completed pilot remain unchanged. Use the workspace overlay with `--label-overrides` for a new snapshot and conversion; the manifest is specific to these recordings.

[spatial-goal-review-v1.json](spatial-goal-review-v1.json) remains the unchanged historical review of all 125 episodes, including both proposed conventions. Its pending-decision marker describes the state before the user's workspace choice. **Do not pass this review file to `--label-overrides`.** Its `artifact_type: spatial_goal_review`, `review_version`, and `reviews` fields differ from the accepted overlay contract.
